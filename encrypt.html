Encrypt library

Runs entirely in this browser. Your password is never sent anywhere and is not stored in the output — only the encrypted result.

Password

This password is the only protection on the file. Anyone who obtains the encrypted file can guess at it offline, with no rate limit, so use something long — four or five unrelated words beats a short complicated one. If you lose it, nothing can recover the contents; you just re-run this tool.
